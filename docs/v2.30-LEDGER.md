## 批次 0：生产救活（恶性 bug）

**根因**：v2.28 在 `backend/src/index.ts` 顶层用 `createRequire(import.meta.url)` 读版本号，esbuild CJS bundle 中 `import.meta` 为空 → 模块求值即抛 `ERR_INVALID_ARG_VALUE` → 全部 `/api/*` 返回 Vercel 裸 500（FUNCTION_INVOCATION_FAILED）。v2.28 部署起生产后端整体不可用；登录页 Turnstile 组件消失（config 接口 500 被前端静默吞掉）只是症状。

- **O1** 版本号改构建期 banner 注入（`process.env.APP_VERSION`），本地回退 cwd 读 package.json；`backend/src/index.ts`
- **O2** `ai-off-verifier.service.ts` 同类雷清除（`fileURLToPath(import.meta.url)` → cwd 推导）
- **O3** 构建期冷启动冒烟门禁：bundle 生成后 `require()` 一次，抛错即 fail build；`scripts/build-vercel-api.mjs`

验证：本地 bundle import + 请求级冒烟（health 返回 503 JSON 且 version 正确）；生产 health 恢复 ok（database/turnstile 全绿）。
