## 实测记录（Playwright 真浏览器，docker postgres:16-alpine 干净库）

- 实测中发现并修复 2 个真实 bug：
  1. events 新 SQL 的 `profile_id = COALESCE($2, profile_id)` 把 `profile_id IS NULL`
     的行全部滤掉（NULL=NULL 不为真）——列表返回空。改为 `($2::int IS NULL OR profile_id = $2::int)`。
  2. `?upcoming=1` 只看 next_occurrence，而该列仅循环事件维护（既有设计），
     一次性未来事件被错误排除。谓词补 `OR date >= CURRENT_DATE`。
- 实测通过：登录 → 日历（URL 翻月同步 ?date=2026-11-01、类型 chips aria-pressed、
  回今天）→ 数据健康新检查项「祝福对象缺邮箱：1 处」→ Todos ?tab=history 直达 →
  年报祝福回顾卡（AI 徽章 + 已发送 1 计数）→ 全部新 API（单条读取/类型筛选/
  upcoming/sort/tag/CSV 导出×2/inbox q+since/audit from-to/goals+habits 排序/todos stats）。
